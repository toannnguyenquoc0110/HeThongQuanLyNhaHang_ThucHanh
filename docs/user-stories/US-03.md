# US-03 : Cập nhật trạng thái phục vụ món ăn

- **User story:** Là nhân viên, tôi muốn cập nhật hoặc tạm ngừng phục vụ một món khi nguyên liệu không đủ hoặc nhà hàng chủ động ngừng bán.
- **Story points:** 5
- **Sprint:** Sprint 1 - Quản lý thực đơn & món ăn
- **Người thực hiện:** Trịnh Tấn Phú
- **Issue:** #3

## Cài đặt
MenuController: action Toggle đảo cờ Stopped của món (Models/Menu.cs, trường Stopped) để tạm ngừng hoặc bán lại. Giao diện ở Views/Menu/Index.cshtml: cột Trạng thái (Đang bán / Tạm hết) và nút Báo hết / Bán lại. Mã nguồn đã nằm trên main từ US-01 vì dùng chung MenuController.
